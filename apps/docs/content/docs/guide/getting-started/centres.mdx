## Overview

A centre is your physical tuition centre. Every record you create is scoped to
one centre, so keeping centres organised matters. You may own more than one
centre and switch between them.

## What you'll see

- A list of the centres you own or belong to.
- The current centre shown in the workspace header.
- A way to create a new centre if you do not have one yet.

![the list of owned centres](/images/guide/getting-started-centres-main.png)

## Common tasks

### Switch centres

1. Select the centre switcher in the workspace header.
2. Pick the centre you want to work in.
3. The workspace reloads for that centre.

### Create a new centre

1. From the centres list, select **Create centre**.
2. Enter the centre details.
3. Confirm to create it. You can now set it up with subjects, classes and staff.

## Notes

- Each centre has its own address and a unique workspace. Records are never
  shared between centres.
- A centre owner can invite other members. See
  [Members](/docs/guide/centre-setup/members).
