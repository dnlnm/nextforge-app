## Overview

**Reports** lets you review operational data and export it for your own use, such
as for follow-up or offline analysis.

## What you'll see

- Summary metrics for the centre.
- Tables of operational data.
- **Export** buttons to download data as CSV.

![the reports page with export buttons](/images/guide/operations-reports-main.png)

## Common tasks

### Run and export a report

1. Open **Reports**.
2. Review the summary.
3. Select an export to download the data.
4. Open the downloaded file in a spreadsheet.

## Notes

- Exports use machine-readable formats; amounts and dates stay consistent with
  the rest of the product.
- Contact and payment data should be handled carefully if shared outside the
  centre.
