## Overview

**Attendance** tracks who was present, absent, late or excused for each class
session. It is the record of student engagement and feeds into reports.

## What you'll see

- A date and week selector.
- Class sessions with student rosters.
- Attendance controls: **Present**, **Absent**, **Late**, **Excused**.
- Session history and summary stats.

![the attendance session panel](/images/guide/operations-attendance-main.png)

## Common tasks

### Mark attendance for a session

1. Open **Attendance**.
2. Choose the date and class session.
3. Set each student's status.
4. Save.

### Review attendance history

1. Open **Attendance**.
2. Select a past date or week.
3. Read the session summaries and stats.

## Notes

- Attendance can also be marked from [Today](/docs/guide/overview/today).
- Statuses are standardised across the centre; use them consistently for
  accurate reporting.
