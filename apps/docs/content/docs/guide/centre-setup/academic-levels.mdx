## Overview

**Academic Levels** represents the grades or stages a student can be in. Levels
group subjects and are used to organise students and classes.

## What you'll see

- A list of levels.
- **Add level** and edit actions.
- A detail view for a level.

![the academic levels list](/images/guide/centre-setup-academic-levels-main.png)

![the add/edit level dialog](/images/guide/centre-setup-academic-levels-dialog.png)

## Common tasks

### Add a level

1. Open **Academic Levels**.
2. Select **Add level**.
3. Enter the level name.
4. Confirm.

### Edit a level

1. Open **Academic Levels**.
2. Select the level.
3. Update the name.
4. Save.

## Notes

- Each student is assigned a level. See [Students](/docs/guide/centre-setup/students).
- Levels appear in the [Academic Planner](/docs/guide/overview/academic-planner).
