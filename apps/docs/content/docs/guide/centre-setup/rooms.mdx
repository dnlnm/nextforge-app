## Overview

**Rooms** lists the spaces where classes are held. Assign a room to a class so
schedules clearly show where each session happens.

## What you'll see

- A list or grid of rooms.
- Each room's name and, where set, its capacity.
- A way to add or edit a room.

![the rooms list](/images/guide/centre-setup-rooms-main.png)

## Common tasks

### Add a room

1. Open **Rooms**.
2. Select **Add room**.
3. Enter the room name and capacity.
4. Confirm. The room is available to assign to classes.

### Edit a room

1. Open **Rooms**.
2. Select a room.
3. Update the details.
4. Save.

## Notes

- Rooms are optional; a class can run without one.
- Assign rooms from the class setup — see [Classes](/docs/guide/centre-setup/classes).
