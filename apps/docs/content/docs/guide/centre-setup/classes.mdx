## Overview

**Classes** is where you set up the groups students belong to. Each class links a
subject to a level, a teacher, a room and a weekly schedule.

## What you'll see

- A list of classes with subject, level, teacher, room and schedule.
- **Create class** and per-class actions.
- A class detail page with its analytics and enrollment actions.

## Common tasks

### Create a class

1. Open **Classes**.
2. Select **Create class**.
3. Choose the subject, level, teacher and room.
4. Set the weekly schedule.
5. Confirm. The class now appears on the schedule.

### View a class

1. Open **Classes**.
2. Select a class.
3. Review the roster and analytics.

## Notes

- A class must be linked to a level and subject before enrollment. See
  [Subjects](/docs/guide/centre-setup/subjects) and
  [Academic Levels](/docs/guide/centre-setup/academic-levels).
- Enrolling students into a class is done from
  [Enrollment](/docs/guide/overview/enrollment).
