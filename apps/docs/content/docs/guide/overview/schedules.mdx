## Overview

**Schedules** is your weekly timetable. It shows when each class runs so the
centre's day is organised and conflicts are visible.

## What you'll see

- A weekly calendar grid of class sessions.
- Class names, times, rooms and teachers on each slot.
- The ability to view by day or week.

![the weekly timetable calendar](/images/guide/overview-schedules-main.png)

## Common tasks

### Review the weekly timetable

1. Open **Schedules**.
2. Move through the week or month.
3. Check every class has a time, room and teacher.

### Fix a scheduling overlap

1. Find the overlapping session in the calendar.
2. Open the class and adjust its schedule times.
3. Confirm. The timetable updates.

## Notes

- Schedules are built from each class's recurring weekly plan. Edit a class to
  change its schedule — see [Classes](/docs/guide/centre-setup/classes).
- Classes that have no schedule yet do not appear on the timetable.
