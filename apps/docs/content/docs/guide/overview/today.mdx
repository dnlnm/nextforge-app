## Overview

The **Today** screen shows the classes scheduled for today and is the fastest way
to mark attendance as the day happens.

## What you'll see

- A list of today's class sessions with times and teachers.
- Attendance controls for each session (Present, Absent, Late, Excused).
- A quick view of who is in each class.

![today's session roster with attendance controls](/images/guide/overview-today-main.png)

## Common tasks

### Mark a class attended

1. Open **Today**.
2. Find the class session.
3. Set each student's status.
4. Save. The session's attendance is recorded.

## Notes

- Attendance can also be done later from
  [Attendance](/docs/guide/operations/attendance).
- Teachers see Today first, so this is also their main screen.
