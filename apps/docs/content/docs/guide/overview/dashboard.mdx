## Overview

The dashboard is the home screen of your centre. It brings together the most
important numbers and tasks so you can see how the centre is doing and what needs
attention today.

## What you'll see

- A **greeting** and today's date, based on Malaysia time.
- **KPI cards** — quick numbers like active students, classes and money owed or
  collected.
- **Today's classes** — what is scheduled for today.
- **Attendance** — a summary of recent attendance.
- **Fee collection** — money collected versus outstanding.
- **Needs attention** — items that require follow up (for example overdue
  invoices).
- **Recent activity** — the latest changes in the centre.

![a populated dashboard with the main widgets](/images/guide/overview-dashboard-main.png)

## Common tasks

### Read today's picture

1. Start at the dashboard each day.
2. Check **Today's classes** for the sessions coming up.
3. Review **Needs attention** for anything overdue or pending.
4. Confirm **Fee collection** is on track.

## Notes

- "Today" follows Malaysia time (`Asia/Kuala_Lumpur`), so it may differ from your
  device timezone.
- Amounts are shown in MYR (RM).
