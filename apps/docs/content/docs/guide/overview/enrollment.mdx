## Overview

**Enrollment** is where you put students into classes. You can enroll a single
student, move a student between classes (transfer), or enroll several students at
once.

## What you'll see

- A list of current enrollments.
- Search and filters to find a student or class.
- A class picker and buttons to enroll, transfer or end an enrolment.

![the enrollment list](/images/guide/overview-enrollment-main.png)

![the enroll / transfer dialog](/images/guide/overview-enrollment-dialog.png)

## Common tasks

### Enroll a student into a class

1. Open **Enrollment**.
2. Select the student.
3. Choose the class and any student-specific fee.
4. Confirm. The student appears in the class roster.

### Transfer a student to another class

1. Find the student's current enrolment.
2. Select **Transfer**.
3. Choose the new class.
4. Confirm. The enrolment moves.

### End an enrolment

1. Find the student's enrolment.
2. Select **End enrollment**.
3. Confirm. The student leaves the class.

## Notes

- Enrolment affects the student's class rosters, attendance and invoicing.
- If you have many students to add, see the import flow under
  [Students](/docs/guide/centre-setup/students).
